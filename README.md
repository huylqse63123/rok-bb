# rok-bb

Bản phát hành beta kín của AutoROK (công cụ học tập cho Rise of Kingdoms trên BlueStacks 5).

- Tải file cài đặt mới nhất ở mục **Releases**.
- Cần **mã kích hoạt** do người phát hành cấp; app hiện "mã máy" lần đầu mở để bạn gửi đi.
- App tự kiểm tra và cài bản cập nhật.

**Lưu ý:** dùng công cụ tự động có thể vi phạm điều khoản của trò chơi và dẫn tới cảnh báo hoặc khóa tài khoản.
Chỉ dùng trên tài khoản bạn chấp nhận rủi ro đó.

Repo này chỉ chứa bản phát hành (`latest.json`, `beta.json`, file cài đặt), không chứa mã nguồn.
